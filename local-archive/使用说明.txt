A股早盘 / 收盘本地归档
=====================

目标目录（本机）：
  D:\Eva-personal\A股开盘前早报归档

这个工具箱做三件事：
1. 把已有 HTML 分成「早盘」和「收盘」两个文件夹
2. 双击 BAT 从 GitHub Pages 拉取最新完整 HTML，存到对应文件夹并打开
3. 生成「本地索引.html」，方便点开历史报告

第一次使用
----------
在仓库里双击：

  local-archive\安装到本机归档目录.bat

它会创建 D:\Eva-personal\A股开盘前早报归档，复制 BAT，并把仓库里已有的早报 HTML 放进「早盘」。

日常使用
--------
到 D:\Eva-personal\A股开盘前早报归档 后：

- 双击「整理归档.bat」：把散落的 HTML 归进 早盘\ 或 收盘\
- 双击「生成早盘报告.bat」：下载最新开盘前早报 HTML（截止 08:30）
- 双击「生成收盘报告.bat」：下载最新收盘报告 HTML（截止 17:30）

需要已安装 Python 3，安装时勾选 Add python.exe to PATH。

文件名
------
早盘\A股开盘前早报_YYYY-MM-DD_0830.html
收盘\A股收盘报告_YYYY-MM-DD_1730.html

收盘自动任务要 17:40 跑完并进入 main 之后，「生成收盘报告.bat」才能下到完整 HTML。
若还没发布，BAT 会提示「还没有发布收盘」，不会编造报告。

不要把 latest.html 当报告保存。那个只是跳转页。BAT 会跟随跳转，保存 r/ 目录里的完整正文。
