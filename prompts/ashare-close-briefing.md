# A股收盘报告增量提示词

提示词版本：0.2.1（2026-09-22）。

本文件叠加在收盘自动任务原提示词一至九条之上，只补充「早晚对照」的内容选择、判定口径和 HTML 呈现，不替换原有交易日判断、15:10 截止、iFinD、九段结构、29 个固定板块、交付、排版及知识星球规则。

## 十、早盘信息—收盘验证总览（必须执行）

收盘报告不能只写「兑现几条、证伪几条」。读者无需另开早报，也必须能从收盘 HTML 看懂早上具体说了什么、为什么在收盘被判为兑现或证伪。

1. **位置必须靠前。** 在「核心摘要」之后、「隔夜外盘」之前，增加独立白色圆角大框「早盘信息—收盘验证总览」，目录中增加入口。第五节「判断跟踪」可保留明细，但不得用它替代靠前总览。
2. **先展示早报来源和总答案。** 写明读取的早报文件名、早报截止时间 08:30、收盘事实截止 15:10；并列展示：
   - 早报风险温度、风格顺序、最关键开盘观察；
   - 收盘风险温度、实际风格顺序、成交变化；
   - 兑现、部分兑现、未兑现、证伪、无法验证各多少条；
   - 一句话说明当天最大的正确点和最大偏差。
3. **逐条展示，不能只转述结论。** 对每项指向当天盘中的判断建立对照行，字段不得少于：
   - 编号；
   - 早报 08:30 原文或保持原意的完整关键句；
   - 「早上在说什么」的白话解释；
   - 涉及板块及代码；
   - 判断方向和前提条件；
   - 15:10 收盘事实（涨跌幅、成交/量能、关键盘中路径，可取得时列出）；
   - 对照状态；
   - 判定理由和对下一交易日的含义。
4. **优先沿用早报判断编号。** 若同日早报已有「当日判断基线」及 `P01`、`P02` 等编号，收盘报告必须原样沿用。旧早报没有编号时，收盘报告可按原文出现顺序补 `P01` 起的编号，并注明「收盘整理编号」。
5. **只核验可核验判断。** 纳入风格顺序、开盘观察、催化方向，以及明确写明承压、占优、补涨或高波动的板块。上一交易日复盘数字、已经公布的宏观数据和纯背景介绍不打分。
6. **条件判断不得丢失前提。** 例如早报写「若指数高开且成交继续收缩，防止快速轮动」，收盘时若成交没有收缩，应判「无法验证（触发条件未成立）」，不能判兑现或证伪。
7. **状态仍只使用原定五种。** 兑现、部分兑现、未兑现、证伪、无法验证。每个状态必须紧邻证据和理由；禁止用模糊词代替状态，也禁止先定状态再挑证据。
8. **催化与行情分开判断。** 公告或政策「已发生」不等于板块方向兑现。事件落地状态与行情验证状态分别写；一天不足以验证产业或业绩效果时，明确写「无法用一天行情验证」。
9. **没有方向就不补预测。** 早报未给某板块当日方向时，写「早报未给当日方向」，不纳入兑现率。不得从早报的板块资料、前日复盘或风险提示中倒推出一个预测。
10. **总览后给出三段简明结论。**
    - 早报最准确的判断；
    - 早报最大的偏差或未覆盖变化；
    - 下一交易日应保留、修正或放弃的观察框架。
11. **移动端可读。** 对照表允许横向滚动；同时用 3 张短卡概括「早报基线、收盘答案、主要偏差」，避免用户必须横向阅读整张表才能理解结论。
12. **知识星球同步。** 星球正文中的「对照早报」不能只写数量，至少补一句早报最重要判断及收盘结论。代码块内直接放标题和正文，禁止出现「知识星球分享文案」「标题」「正文」等提示词。
